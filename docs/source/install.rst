Getting Started
===============



Installation
------------

The MuonDataLib package is easy to install using :code:`pip`.
The library is available on `PyPi <https://pypi.org/project/MuonDataLib/>`_ and can be installed with pip:

.. code-block:: python

    python -m pip install MuonDataLib

Reporting Issues
----------------

To report an issue please create a `github issue <https://github.com/ISISMuon/MuonDataLib/issues/>`_ with the details of the bug.
